# Realm Idle Tools

Browser-based character setup, combat simulation, XP planning, gathering tools,
item catalogue, forge planning, and event candy planning for Realm Idle.

## GitHub Pages

The website is ready to serve directly from this repository root. In
**Settings → Pages**, select **Deploy from a branch**, **main**, and **/(root)**.
The `.nojekyll` file enables direct static-file hosting.

Open `index.html` to browse the tools. No build step or backend is required.
Character profiles remain in the visitor's browser; JSON import/export is available
for backups and transfers between devices.

## About

Independent community tools using Realm Idle game data and artwork.
Calculations are estimates and explain their assumptions within each tool.
