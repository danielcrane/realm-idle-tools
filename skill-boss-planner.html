ABOUT THE MODEL

Personal Planning, with the Source’s Boundaries.

Unlock gathering bosses by defeating the Darkwood Forest boss, or buying the Gathering Pass Scroll (1,000,000 gold). Starting an attempt requires a confirmed server clock and online account reservation. Five attempts are available per game week; the planner does not reserve them.

The estimate is 200 ticks at the selected gathering speed: one full 120-second attempt. Equipment, potion, candy, event status, weather and season stay fixed for this estimate. It assumes the attempt completes before the weekly reset.

Only the selected equipment changes. No mid-attempt gear swaps, automatic level gains, server lag, account inventory validation or live community state are modeled. Any of the three bosses can be explored even outside its rotation. Initial weather, season, event status and rotation use your device clock, not a confirmed server clock.
